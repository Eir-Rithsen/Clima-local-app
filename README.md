# 🌤️ Clima Local App con Amazon Q Developer

Este proyecto fue desarrollado como parte del **Desafío 3 de AWS - Amazon Q Developer**.  
Se trata de una aplicación web sencilla que muestra el **clima actual de tu ubicación** en tiempo real utilizando la **API de geolocalización del navegador** y la **API de OpenWeather**.

---

## 🛠️ Tecnologías utilizadas
- Node.js + Express (servidor)
- HTML, CSS, JavaScript (frontend)
- API de Geolocalización (navegador)
- OpenWeather API (clima)

---

## 🤖 Uso de Amazon Q Developer
Durante el desarrollo, **Amazon Q Developer** me asistió en:
- Generar la base del servidor en Express.
- Sugerencias para consumir la API de OpenWeather.
- Manejo de errores en el `fetch` del clima.
- Ideas para estructurar el proyecto y mejorar la presentación.
